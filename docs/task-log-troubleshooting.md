# 自动任务日志排查

## 音乐人签到

未开始的签到任务可能返回 `userMissionId=0`。访问音乐人中心后，程序只接受同一 `missionId`、同一 `period` 唯一的新分配 ID；已有有效用户任务 ID 不允许被替换。短暂未同步时最多复查三次，不重复发送访问打点。领奖后仍须查询到同一用户任务状态 `100` 才会显示成功。

任务日志显示任务 ID、用户任务 ID、周期与官方状态，便于区分未分配、周期切换和真正未完成。

## 音乐合伙人推荐

iOS UA 的应用版本和系统版本须有效；build 号可以缺省。没有 build 号时不发送该字段，不推测版本，也不借用 PC Cookie 的 build 号。Android 仍须配置相应 XEAPI UA。

CDN GET 遇到临时断连、超时或 HTTP 5xx 时最多重试一次；证书错误、明确的 DNS 不存在、HTTP 401/403/429 不自动重试。日志只显示受控错误分类、HTTP 状态和已验证的 CDN 域名，不输出带签名 URL、Cookie 或 Token。笔记、乐评发布及互动上报不使用 CDN 重试逻辑，原有发布记录、防重发和延迟删除行为保留。

评分接口返回 `405 / 今日没有更多可评定歌曲啦` 表示服务端当日可评资源已用尽，程序会停止评分并保留未达目标的结果，不绕过限制或把失败计为成功。

## VIP 与云贝

同一轮批量运行中的 VIP 子任务只执行一次；后续轮次复查官方状态，不重复领券。官方返回的原生领券页 `ReactNativeVip/welfarecenter` 若没有 `view_task_id`，会明确标为需 App 完成，不再用任务编号拼出浏览参数或领取无关商家券。带有明确任务上下文的既有路径继续保留；商家券接口回执不代表成长任务完成，实际任务仍未完成时如实展示。

云贝领奖返回 `false` 时不能证明新增到账。日志保留未确认结果，并显示候选来自待办接口还是本轮完成变化、是否有 depositCode、完整列表的官方状态。同一领奖凭据在本次运行内只尝试一次，实际收益使用余额与收益接口核对。

新版完整云贝列表的 `userTaskId` 是父任务编号，实际奖励编号位于 `taskPointDetail[].userMissionId`。程序按奖励子任务和周期关联待办凭据，保留实际领奖参数；有奖励子项时不再将父任务编号补成另一条领奖请求。不同奖励阶段和周期分别处理，只有旧版无子项的平面列表才保留本轮完成变化的兼容逻辑。

## 指定歌曲播放

音频下载与合伙人推荐共用 HTTPS、CDN 域名校验和无 Cookie 的只读客户端，接受合法的分块音频传输；单个音频上限为 32 MiB，网络及读取错误仅记录受控诊断。

获取不到匹配歌曲的可用音频或下载失败时，跳过该歌曲，不等待完整时长、不发送播放完成上报、不增加播放计数。相同歌曲本轮不再循环重试，其他可用歌曲继续处理；可用歌曲不足而未达目标时报告真实完成数量。下载成功时只补足剩余播放时间，取消后停止后续上报。

以下跳过项需要配置或在 App 操作，不属于接口执行成功：

- 每日推歌、锦鲤许愿缺少同一账号配套的移动端 Cookie、UA 或 `accounts.antiCheatTokens`。
- 乐迷团播放未开启 `fansgroup.webSession`；该选项仅适用于乐迷团播放。
- 探索小众歌曲的子任务开关关闭，或未加入当前任务组。
- 官方未下发音乐人 VIP 进阶任务时，无法据此推断领取资格。
- 设置启动图、外部平台关注、玩消消乐和设置双人关系等尚无对应自动执行实现，需在 App 完成。
