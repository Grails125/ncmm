# v1.2.9 差异整合：第 1 组基础修复

本组基于 PR #5 合并后的 `a7ee383`，保留现有音乐合伙人原生评分、积分、乐评及配置能力。

## 已完成范围

- 插件运行全局 `--config`、`-c`、`--home`、`--debug` 在配置初始化前解析；`--` 后的参数不参与宿主解析。WebUI 生成的插件参数加上独立边界。
- 插件立即运行使用服务生命周期上下文：HTTP 响应结束不会停止任务，服务停止和任务停止仍有效。
- 插件在线安装统一 `target/tag/token` 契约，兼容 `repoOrURL`；支持仓库简称、完整 GitHub URL、安装包直链、指定 Release Tag 和私有 GitHub 凭据。CLI 与 WebUI 共用 `internal/plugininstall.Options`。
- 普通密码登录页显示后端实际版本；没有版本时显示 NCMM，不再回退到硬编码版本。
- 新配置及日志库默认单文件上限由 100 MB 改为 5 MB；已有配置中的 100 MB 或其他自定义值在迁移时保留。

插件常驻进程、市场、更新探测、来源记录和下载代理属于后续第 3 组，本组没有提前启用。安装测试仅使用临时目录中的无效可执行文件内容，不执行第三方插件。

## 验证

- Go 回归覆盖宿主参数初始化顺序、`--` 边界、请求/服务取消、安装请求旧新字段兼容、仓库 URL、Tag URL 转义、私有 Token、直链及无效目标、日志迁移值保留。
- Node 单测覆盖普通登录版本、未知版本、安装表单契约及结构化插件参数边界。
- `tests/webui_base_fixes.js` 在真实 Chrome 和全新临时数据目录中覆盖设置密码、清除测试登录态后重新登录、三种安装表单。所有安装请求由浏览器测试替身返回，业务运行请求被拦截。
- 运行方式沿用 `tests/run_webui_browser.js BINARY tests/webui_base_fixes.js HOME`。测试配置须关闭 updater 检测与自动更新，HOME 使用新的隔离目录。

本组没有修改用户数据，没有执行真实账号任务；本地 Docker 联合部署与 PR 发布由整合流程单独验收。
