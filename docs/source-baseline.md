- 恢复范围：缺失的源码与构建文件、配套 v1.2.2 默认配置和忽略规则。现有公开文档、独立工具和脚本保留，版本差异以本说明为准。

## 版本边界

这是基于 v1.2.2 的可维护分支，**不是 v1.2.9 主程序源码的恢复**。`docs/changelog.md` 中 v1.2.3 至 v1.2.9 的条目仅作为上游历史资料，不能视为当前可构建版本已包含的功能。后续新增的插件市场、容器内热更新及音乐人任务修订等不能仅凭文档宣称已移植。

不要将已有 v1.2.9 实例的数据目录直接交给本版本；应先备份，并使用独立数据目录验证配置和任务兼容性。当前整合的交付目标是在这个完整源码基础上内置音乐合伙人评分，共用账号、批量任务、WebUI 调度、日志和通知。

## 已补齐的音乐人兼容性修复

基于上游 [issue #33](https://github.com/3899/ncmm/issues/33) 的任务样例及 [v1.2.9 更新说明](https://github.com/3899/ncmm/blob/main/docs/changelog.md)，当前实现补齐以下两项；这不表示已同步全部 v1.2.9 功能：

- 有效播放支持旧版次数进度及 `mission_code_recently_play_effect_count_v2` 百分比进度。新版从明确的播放目标文案提取次数，再按剩余百分比向上取整；例如目标 650 次、进度 7% 时预计还需 605 次。近 30 天历史总播放量不参与本期缺口计算；目标缺失、冲突或进度异常时记录原因并跳过，不猜测目标。
- VIP 领取每次先刷新官方状态，成功记录按账号及 `furtherVipGetTime` 隔离。旧版自然月记录不再参与判断，预约期不记录成功，到期且官方允许领取后才提交，仅接口明确成功后保存。未返回有效周期时依赖当次官方状态，不保存无法区分周期的记录。

播放成功上报数量只是本轮执行结果，是否计入有效播放以官方进度为准。领取接口保留原有账号 Token 要求，音乐人客户端不自动重试写请求；预约时间到达后由下一次已启用的定时或手动任务检查领取。本次不修改音乐合伙人评分、配置及积分展示。

## 已补齐的账号与日常任务修复

参考上游 [v1.2.5](https://github.com/3899/ncmm/releases/tag/v1.2.5)、[v1.2.6](https://github.com/3899/ncmm/releases/tag/v1.2.6) 及 [v1.2.9 更新说明](https://github.com/3899/ncmm/blob/main/docs/changelog.md)，在现有源码上补齐：

- 会员礼品领取不再要求或发送 `antiCheatToken`，音乐人 VIP 领取的 Token 要求保持不变。新增 `vipMemberGift.enableGiftSecondaries: false`：辅助账号仍可领取，赠送需显式开启此项及 `enableGift`；显式 `--cookie-file` 沿用单账号按主账号执行的行为。
- 会员礼品错误码 `12200`、`12206` 以及领取返回成功但会员天数为空或零时，向互助服务上报无效邀请，不记录领取成功；无法上报时终止本次匹配，避免继续复用该邀请。
- 指定歌曲播放按当前听歌账号的真实 Artist ID 排除本人及合作作品，保留上传者 ID 判断；昵称不再作为归属依据。身份查询失败会记录警告并仅按上传者判断，不阻断整个歌池，也不会将主账号的作品误当成辅助账号本人的作品。
- 普通 VIP 的“每日听 3 首 VIP 歌曲”从自动执行队列跳过，提示在 App 内完成，避免无效等待；其他乐签、成长值领取继续执行。
- WebUI 验证并保存 Cookie 或扫码登录后，账号中心与仪表盘立即采用该账号的登录验证结果。状态随配置保存；登录前启动的旧任务不能覆盖新登录状态，之后运行的任务仍能更新失效结果。没有验证记录的旧账号保持未知，不能仅因文件存在就显示有效。

以上修复保留原生音乐合伙人评分、范围配置、分值乐评和周期积分展示，不表示已同步其他上游功能。

## 已补齐的预设、调度与配置体验

- 新工作区默认关闭乐迷团；四种日常预设也关闭乐迷团。音乐人冲刺预设不额外开启公共图文和每日推歌，保留音乐人 VIP 笔记；仅签到预设包含会员礼品。启动升级不重置已有任务开关，只有主动应用预设才修改对应选项。
- 每条 WebUI 定时规则支持 `randomDelaySeconds`（0～86400 秒），Cron 触发后在 0～上限间随机等待，手动运行立即执行。等待不占执行名额或账号资源，参与重叠检查，可以停止；日志记录本次延迟，等待状态显示最早执行时间。
- 指定歌曲播放支持 `playids.playlistIds` 和可重复的 `--playlist-ids`，读取当前听歌账号可访问的网易云歌单，与歌曲 ID、文件来源合并去重。ID 列表支持中文分隔符及 `#`、`//` 注释，保留现有本人作品过滤。
- 手机规则配置改为横向模块选择与单模块展示，使用页面纵向滚动；搜索可跨模块，保存栏固定在底部。桌面仍使用连续配置流，YAML 和乐评编辑保留。

音乐合伙人评分、范围配置、各分值乐评及本期积分保持原有功能；上述增量不表示已同步全部上游实现。

## 基线验证

在恢复来源上使用 Go 1.25.0 执行 `go build .` 和 `go test ./...` 均通过。真实网易云接口测试受 `NCMM_TEST_LIVE` 控制，验证时未启用；没有进行账号登录、评分、签到或通知发送。这些结果不代表真实账号或线上接口验收。
