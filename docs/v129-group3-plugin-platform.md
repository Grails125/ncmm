# 插件平台（v1.2.9 对齐，第 3 组）

音乐合伙人评分、积分展示和原有任务继续由 NCMM 原生执行，本组只扩展外部插件管理。

## 常驻插件

`plugin.json` 可声明 `"type": "daemon"`；省略时为一次性 `task`。插件中心显示运行状态、启动、停止、重启、启动参数、自启动及最近日志。新安装默认不自启动；只有明确保存的“随 NCMM WebUI 自动启动”才随 WebUI 启动。CLI `plugin run`、任务保存、立即运行和调度实际执行均拒绝 daemon，已有 daemon 定时配置被跳过。

常驻进程与 WebUI 生命周期绑定，使用既有进程树监督器。停止和服务退出等待进程回收，升级前停止并释放 Windows 文件锁，成功后恢复原运行状态，安装失败也尝试恢复旧进程。异常退出可在卡片看到；不会无休止自动重启。`plugin-daemons.json` 保存在当前 home，记录自启动和参数，权限 0600。每个插件的当前/最近一次输出仅保留 1 MiB 内存尾日志，停止后仍可查看，WebUI 重启后清空；不写入任务日志或账户业务记录。

## 在线市场与安装

公开市场提供 [QQBot](https://github.com/crossgg/ncmm-qqbot) 入口和作者项目说明，不列出不可用的私有市场，也不在浏览市场或完成安装时执行第三方插件。QQBot 需要用户在插件中配置自己的官方机器人凭据；宿主不会代注册账号或自动测试真实消息。

安装继续支持 owner/repo、完整 GitHub 仓库 URL、Release 包直链和本地上传。Tag 真正用于选取指定发布。下载镜像默认直连，可选 gh-proxy.com、ghproxy.net、githubproxy.cc 或无认证信息的自定义 HTTPS 镜像；CLI 使用 `-p/--proxy`。公开安装包镜像失败后回落直连；提供 Token 时始终直连 GitHub，Token 不写入 source.json、缓存或浏览器存储，也不会转发给 CDN、HTTP 降级地址或 GitHub 子域名。

仓库发布安装记录标准 `source.json`：仓库、实际 Release Tag、安装时间、是否私有及公开镜像选择。不会将 `latest` 当实际版本，也不保存 Token、签名下载 URL。直链/上传无可信仓库来源，不自动推断升级仓库。

## 更新与文件保留

已安装公开仓库通过 HEAD `releases/latest` 的跳转检测实际 Tag；使用已选择的公开镜像时，失败或异常跳转会回落直连，接受的最终位置必须是同一 GitHub 仓库的 `releases/tag`。自动检查结果在 home 下 `plugin-updates.json` 缓存 24 小时，手动检查有 60 秒防抖，重启仍生效。后台不使用私有凭据：私有插件由用户在本次升级时提供 Token。

升级按钮从已安装可信来源选择最新发布，保持插件身份不变。包先限量解压并校验，拒绝越界路径、符号链接和重复文件；完整新目录就位后替换旧目录。现有 config.yaml 优先保留；其他未被新版同名包文件替代的本地数据保留。临时/备份目录不参与插件发现。标准独立目录安装支持一键升级；旧式平铺安装需手动迁移到独立目录。安装包/解压内容限 256 MiB；保留本地数据限 256 MiB / 4096 文件，超限提示手动备份升级。

手动上传/重新安装正在运行的插件前应先停止它；使用“升级”按钮则自动完成停止和恢复。目录替换有失败回滚，但进程被操作系统强制终止或机器断电不等同完整事务；隐藏临时/备份目录会保留供人工恢复，不会作为另一个插件启动。

## 验证

- 离线 Go 测试覆盖实际 Tag、Token 边界、镜像回退、HEAD 跳转校验、缓存/防抖、私有后台不联网、错误包不覆盖旧文件、config 和本地数据保留、daemon 禁止作为任务。
- 常驻插件测试仅使用 Go 测试辅助进程，覆盖重复启动、参数/自启持久化、运行期间状态读取、停止/异常退出/服务退出、升级成功与失败恢复、调度过滤、日志尾缓冲及鉴权。
- Chrome 测试模拟市场、安装和升级网络，覆盖操作失败恢复、重复点击、版本徽标、任务过滤与 320/390/768 像素布局。未安装或执行 QQBot 等真实第三方插件，未执行真实账号任务或发送消息。
